## النتيجة التشغيلية النهائية

كل أثر مالي في WLT يُسجل Journal ذرية متوازنة ذات source reference/idempotency/currency/effective time. Entries المصدقة immutable؛ التصحيح Reversal أو Adjustment جديد، لا update/delete. يمكن إعادة بناء الأرصدة والتقارير والمصالحة من Ledger.

## تشخيص الحالة الحالية

### الموجود
- WLT ledger domain ومجموعة اختبارات operator context.
- payment/COD/refund/settlement capabilities تعتمد القيود.

### الناقص
- journal schema/invariants كاملة.
- account/currency compatibility.
- source uniqueness/idempotency scope.
- reversal/adjustment lineage.
- posting transaction boundaries.
- rebuild/reconciliation/audit evidence.

### الخاطئ أو الممنوع
- unbalanced journal أو partial entries.
- تعديل/حذف posted entry.
- duplicate source financial effect.
- reversal مرتين أو reversal بلا الأصل.
- floating-point amounts.

### التصحيح المطلوب
- posting service واحد.
- DB constraints/triggers or transaction checks للـdebit=credit.
- integer minor units/currency.
- immutable status بعد POSTED.
- reversal references and one-per-policy.
- no direct table writes خارج domain.

### الإضافات المطلوبة
- Ledger inspector read-only.
- rebuild/checksum/reconciliation tools.
- negative migration/invariant tests.

## Control Panel

- search journals by source/correlation/account/time.
- details: entries، currency، effective time، status، reversal lineage.
- controls: request reversal/adjustment عبر governed command، no edit/delete.
- masked actor/account refs وصلاحيات فصل duties.

## العقود والبيانات

- journal header/entries/source/idempotency.
- atomic transaction وbalanced constraint.
- posted immutable permissions.
- reversal uniqueness/lineage.
- partition/index/retention without deleting legal history.

## الاختبارات الآلية

- unbalanced journal.
- duplicate source/idempotency.
- concurrent post.
- partial transaction fault.
- cross-currency entries.
- update/delete posted entry.
- reversal twice/reversal of reversal policy.
- rebuild balances/reports.

## التجريب اليدوي

1. أنشئ payment/COD/refund/commission entries.
2. افتح journals في Control Panel.
3. حاول unbalanced/cross-currency/direct update.
4. أعد نفس source بالتزامن.
5. نفّذ reversal وكررها.
6. عطّل العملية بين entry writes.
7. أعد بناء balances والتقارير وقارن.
