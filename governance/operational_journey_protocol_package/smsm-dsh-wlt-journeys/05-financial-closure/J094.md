## النتيجة التشغيلية النهائية

تنتج WLT تقارير مالية معرفة بمقياس/فترة/عملة/timezone/freshness ومصالحة مع Ledger. تعرضها DSH عبر facade scoped؛ لا frontend/DSH aggregation authoritative. كل export مدقق ومقنع.

## التشخيص

- **الموجود:** dashboards/summaries لكل actor والLedger.
- **الناقص:** report registry، currency/time policy، snapshots/rebuild، scope/minimum disclosure، exports، Ledger reconciliation.
- **الخاطئ:** UI sums، DSH revenue/net calculation، cross-scope، stale بلا as_of، raw PII/bank export، Dashboard formula منفصلة.
- **التصحيح:** WLT report registry/APIs، snapshots/checkpoints، facade/view models فقط، remove local aggregations.
- **الإضافة:** definitions drawer، data quality، export audit، mismatch link.
