## النتيجة التشغيلية النهائية

تنتج WLT تقارير مالية وملخصات تجارية معرفة بمقياس/فترة/عملة/freshness ومصالحة مع Ledger. تعرضها أسطح DSH عبر facade scoped ومقنعة، دون تجميع authoritative في frontend أو DSH. كل export مصرح ومدقق ويحترم PII والحدود.

## تشخيص الحالة الحالية

### الموجود
- finance dashboards/summaries وactor wallet/commission/settlement/payout panels.
- WLT Ledger ومصادر مالية مكتملة في الرحلات السابقة.

### الناقص
- financial metric/report registry.
- period/timezone/currency/conversion policy.
- snapshot/freshness/checkpoint/rebuild.
- scope isolation وminimum disclosure.
- pagination/export jobs/security.
- totals-to-ledger reconciliation.

### الخاطئ أو الممنوع
- UI يجمع pages ويعرض total authoritative.
- DSH يعيد حساب revenue/net/commission/debt.
- cross-partner/actor report.
- stale snapshot بلا `as_of`.
- export يحتوي raw PII أو bank data.
- Dashboard العام يعيد تعريف أرقام Finance بمعادلات مستقلة.

### التصحيح المطلوب
- WLT report registry وتعريف كل metric ومصدره وصيغته وفترته.
- report APIs server-side مع scope/pagination/export jobs.
- snapshots/checkpoints/rebuild ومصالحة Ledger.
- DSH facade/view models للعرض فقط.
- إزالة frontend aggregations/constants/duplicate report queries.

### الإضافات المطلوبة
- freshness/data-quality banners.
- report definition drawer.
- audit لكل export وsensitive drill-down.
- reconciliation link عند mismatch.

## التطبيقات

### App Partner
- dashboard: balance، revenue، commissions، obligations، settlements، payouts، refunds، COD حسب الصلاحية.
- filters period/currency/store، details، statement/export إن معتمد.
- no local summation؛ كل total من response واحدة أو report version موحدة.

### App Captain / App Field
- summaries للعمولات/custody/payouts فقط ضمن Actor scope.
- لا Partner/platform totals.
- freshness/status واضحة.

## Control Panel — جميع الأقسام المتأثرة

### المالية
- التقارير الكاملة مع definitions، periods، currencies، source lineage، exports.

### التحليلات
- يعرض مؤشرات مالية مستوردة من WLT فقط، مع link لتعريف التقرير؛ لا يعيد حسابها.

### Dashboard
- KPIs العليا references إلى report IDs/versions نفسها، لا queries منفصلة.

### الشركاء
- Partner Detail يعرض scoped commercial summary وlinks للتقارير/settlements.

### الموارد البشرية
- Captain/Field profile يعرض summaries الخاصة بالشخص فقط.

### العمليات
- يعرض financial blocker/status المطلوب للتشغيل فقط، لا التقارير الكاملة.

### التدقيق
- exports، sensitive views، report generation، parameter changes مسجلة.

## العقود والبيانات
