## النتيجة التشغيلية النهائية

WLT تملك accounts/wallets، والرصيد مشتق من Ledger/checkpoints verified، لا عمود قابل للتعديل. كل Surface يرى subset scoped عبر DSH facade مع `as_of` وfreshness؛ لا set balance أو aggregation authoritative خارج WLT.

## التشخيص

- **الموجود:** wallet/account summaries وLedger domain.
- **الناقص:** ownership/type/currency lifecycle، available/pending/held definitions، checkpoint/rebuild، closed/suspended behavior، masking.
- **الخاطئ:** direct balance update، raw DSH copy، frontend sum، cross-actor access، unsupported currency.
- **التصحيح:** immutable owner/currency، ledger-derived query، short projection، object auth، remove mutable balance.
- **الإضافة:** restrictions/reasons، multi-currency presentation، reconciliation diagnostics.
