## النتيجة التشغيلية النهائية

يمر كل وصول مالي من أسطح DSH عبر Finance Facade واحدة داخل DSH. تتولى DSH التفويض التشغيلي وتجميع context وربط order/actor/operator scope، بينما تنفذ WLT القراءة أو الأمر وتملك النتيجة المالية. لا يوجد Browser/Mobile direct WLT URL ولا env عام ولا types/statuses مالية يدوية موازية.

## تشخيص الحالة الحالية

### الموجود
- DSH finance proxy/bridges وWLT shared frontend facades.
- حراس `wlt-financial-boundary` وgenerated WLT clients.
- service auth وoperator context patterns.

### الناقص
- registry كامل لكل finance operation ومستهلكيها.
- scope propagation وobject authorization matrix.
- timeout/retry/idempotency/result lookup policy موحدة.
- error translation دون فقد semantics.
- network/runtime proof أن الأسطح لا تصل WLT مباشرة.
- cache/projection freshness وعلامات stale.

### الخاطئ أو الممنوع
- `EXPO_PUBLIC_WLT_*` أو `NEXT_PUBLIC_WLT_*`.
- fetch مباشر من frontend إلى WLT.
- DSH يعيد حساب أو يعدل response مالية.
- duplicate mutation بسبب retry بعد timeout.
- mapping status مفتوح أو strings محلية.

### التصحيح المطلوب
- operation registry: owner، route، permission، idempotency، readback، timeout، errors.
- DSH internal WLT client واحد لكل capability.
- facade OpenAPI generated لكل Surface use case.
- remove direct URLs/deep imports/manual types.
- fail-closed authorization وunknown-result recovery.

### الإضافات المطلوبة
- finance boundary diagnostics وtrace correlation.
- contract tests لكل operation.
- runtime network capture وnegative direct-call test.

## كل الأسطح

- لا تعرف عنوان WLT أو provider.
- تعرض `loading | stale | unavailable | pending | unknown | resolved` من facade contract.
- كل mutation لها زر تحقق من النتيجة بدل إعادة عمياء.
- financial copy/amount formatting من WLT presentation utilities المعتمدة.

## Control Panel

- Finance workspace يستخدم DSH routes فقط.
- يظهر DSH authorization context وWLT reference masked.
- لا يوجد force-success أو direct ledger mutation.

## العقود والباك إند

- DSH facade endpoints منفصلة reads/mutations.
- service auth بين DSH/WLT، actor/operator scope signed or trusted headers محكومة.
- idempotency/correlation propagated end-to-end.
- error vocabulary preserves `forbidden`, `conflict`, `unknown`, `unavailable`, `validation`.
- no financial persistence في DSH إلا references/projections قصيرة العمر المعلنة.

## الاختبارات الآلية

- direct WLT URL/import/env scan.
- forged actor/operator scope.
- WLT timeout/5xx/malformed response.
- duplicate mutation/retry.
- unknown result ثم lookup.
- stale projection/readback.
- operation registry coverage لكل UI control.

## التجريب اليدوي

1. افتح كل لوحة مالية في الأسطح الخمسة وسجل الشبكة.
2. تحقق أن كل request يذهب إلى DSH فقط.
3. عطّل WLT واختبر رسائل degradation.
4. نفّذ mutation ثم اقطع الشبكة بعد commit.
5. حاول scope مزور وActor آخر.
6. قارن correlation بين DSH/WLT والـlogs.
7. شغّل scan للـenv/imports/direct URLs.
