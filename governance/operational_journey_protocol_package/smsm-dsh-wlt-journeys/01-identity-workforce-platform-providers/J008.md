## النتيجة التشغيلية

سجل مركزي واحد للأدوار والصلاحيات وحزم الوصول والتكليفات، يطبق deny-by-default وleast privilege، مع تطابق visibility في الواجهة وenforcement في Backend دون أن تصبح الواجهة مصدر سلطة.

## الحالة الحالية

| البند | الحكم |
| --- | --- |
| Permission vocabulary | موجود مركزيًا إجمالًا، يحتاج جرد كامل مقابل Go/OpenAPI/UI |
| Bundles/roles | موجودة، لكن convergence مع Identity migrations والأسطح غير مثبتة |
| UI visibility | توجد guards/controllers، التطابق الكامل غير مثبت |
| Parallel truth risk | role maps وvisibility maps وhardcoded strings داخل الأسطح |
| المطلوب | owner واحد، generated types، negative guards، effective-permission readback |

## Control Panel

- صفحات roles/permissions/bundles/assignments مع search/filter/history.
- create/edit/archive bundle، assign/revoke actor، effective permissions preview.
- warnings للتعارض أو privilege escalation.
- لا يسمح self-grant أو تعديل permission vocabulary من UI إن لم يقر Product Truth.
- كل تغيير يحتاج reason/audit وreadback.

## التطبيقات

- تستقبل capabilities/allowedActions من الخادم أو projection موثوقة.
- تخفي أو تعطل التحكم لتحسين UX فقط.
- إذا استُدعيت العملية مباشرة يجب Backend رفضها.
- عند revoke أثناء session تتحدث الواجهة وتمنع queued privileged actions.

## التقنية

- كل permission literal مسجل في vocabulary المركزية ومربوط بعقد/handler.
- role/bundle assignment effective-dated عند الحاجة.
- claims لا تحمل صلاحيات طويلة العمر بلا version/revalidation.
- object authorization في J009 منفصل عن permission العام.
- caches تبطل عند التغيير.
- لا `isAdmin` عام أو wildcard غير مبرر.

## الاختبارات

- unknown permission في Go/OpenAPI/UI.
- self-grant وcross-scope assignment.
- conflicting roles/deny precedence.
- revoke أثناء session/offline.
- UI hidden + direct API call.
- bundle update وتأثيره على Actors الحاليين.
- كل قسم مذكور يربط Controls إلى permission canonical واحدة.

## التجريب اليدوي

1. أنشئ Bundle محدودًا في `/dsh/administration` وعيّنه لActor.
2. افتح HR وPartners وOperations وFinance وتحقق من navigation والتحكمات.
3. جرّب API مباشرة لعملية مخفية.
4. ألغِ assignment أثناء الجلسة وأثناء offline.
5. اختبر Operator يحاول منح نفسه صلاحية حساسة.
6. افتح `/dsh/platform/policies` وتحقق من vocabulary drift/readback.
7. راجع effective permissions وaudit.
