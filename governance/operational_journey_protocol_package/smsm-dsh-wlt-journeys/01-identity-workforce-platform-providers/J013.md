# J013 — جاهزية الميداني

```yaml
owners: [Workforce, DSH]
actors: [OPERATOR, FIELD]
surfaces: [control-panel, app-field]
dependencies: [FOUNDATION-00, J012]
assessment_status: NOT_ASSESSED
closure_status: OPEN
```

## النتيجة التشغيلية

تمكين Field فقط عندما يكون Actor وprofile وemployment وshift وassignment للمنطقة/الشريك/المتجر فعالين، وإعادة التحقق عند كل mutation وعند reconnect.

## الحالة الحالية

- **الموجود:** app-field وWorkforce/DSH scope concepts.
- **غير المثبت:** gate موحد، effective ranges، offline revoke behavior، task filtering.
- **الخاطئ المحتمل:** profile role فقط، hardcoded field user، local area IDs، mutation بعد انتهاء assignment.
- **التصحيح:** readiness endpoint وtrusted assignment context وbackend recheck.
- **الإضافات:** blocked reasons، shift/timezone handling، task-cache invalidation.

## Control Panel

- Field profile checklist: Identity، employment، supervisor، shift، city، active assignments، documents.
- assignment create/end/history مع effective time.
- لا زر `تفعيل` عام يتجاوز النواقص؛ يعرض كل blocker.

## App Field

- شاشة readiness قبل work queue.
- يعرض supervisor/shift/areas/tasks الحالية فقط.
- حالات: no assignment، shift inactive، outside area، profile incomplete، suspended، offline stale.
- كل task/mutation يعرض scope الحالي.
- عند revoke أثناء offline: queue تبقى للعرض لكن لا ترسل؛ تظهر conflict/action expired.

## التقنية

- trusted context من Workforce assignments لا request headers.
- DSH task queries مفلترة بالassignment الفعال.
- version/effective time في mutations.
- local cache partitioned by actor+assignment version.
- no bootstrap account في production path.

## الاختبارات

- assignment missing/expired/future.
- shift boundary/timezone.
- cross-area/store IDs.
- revoke during offline queue.
- supervisor/role mismatch.
- app reinstall/cache stale.

## التجريب اليدوي

1. فعّل Field بلا assignment ثم أضف assignment.
2. ابدأ shift وافتح work queue.
3. حاول task خارج area/store.
4. ألغِ assignment أثناء offline وأرسل action بعد reconnect.
5. اختبر انتهاء shift وActor suspension.
6. تحقق من Control Panel وaudit.

## الإغلاق

`field_readiness_bypasses=0; cross_area_store_actions=0; stale_offline_privileged_actions=0; local_scope_truth=0; all_blocked_states_visible=PASS; evidence_sha=CURRENT_SHA`.
