# J004 — إصدار التفعيل وإلغاؤه وقراءته

```yaml
owner: Identity
actors: [OPERATOR, PARTNER, CAPTAIN, FIELD]
surfaces: [control-panel, app-partner, app-captain, app-field]
dependencies: [FOUNDATION-00, J003]
assessment_status: NOT_ASSESSED
closure_status: OPEN
```

## النتيجة التشغيلية

إصدار رمز تفعيل قصير العمر لActor موجود ومؤهل للسطح، إظهاره مرة واحدة فقط، ثم إلغاؤه أو إعادة إصداره دون وجود رمزين فعالين خارج السياسة.

## الحالة الحالية

| بند | الحكم الحالي |
|---|---|
| endpoints التفعيل | مثبتة إجمالًا، تحتاج mapping دقيق |
| raw code handling | غير مثبت في logs/storage/responses |
| single-use/hash/expiry | يجب إثباته من DB/handler |
| free-phone issuance | يجب منعه لصالح اختيار Actor موجود |
| revoke/reissue races | غير مثبتة |

### الناقص والخاطئ المطلوب كشفه

- إدخال هاتف حر بدل اختيار Actor.
- إصدار رمز لسطح أو role غير متوافق.
- تخزين raw code أو إظهاره بعد أول response.
- أكثر من رمز فعال أو عدم إبطال السابق.
- عدم وجود attempt limit/audit/correlation.

## Control Panel

- entry من صفحة Actor/Workforce profile لا form هاتف منفصل.
- يعرض الاسم/Actor ID/role/surface/status قبل الإصدار.
- زر `إصدار رمز` مع confirmation.
- response يعرض raw code مرة واحدة مع زر Copy accessible وتحذير.
- بعد إغلاق modal أو refresh يعرض masked code وexpiry/status فقط.
- أزرار `إلغاء` و`إعادة إصدار` حسب الحالة.
- حالات: no actor، wrong role، already active، revoked، expired، rate limited، unknown result.

## App Partner/Captain/Field

- لا تصدر الرموز.
- شاشة التفعيل تستقبل الرمز في J005.
- عند إلغاء الرمز أثناء الإدخال يظهر رد محدد ولا retry عمياء.

## التقنية

- OpenAPI operationIds مستقلة: issue/read/revoke/reissue.
- raw code لا يكتب في DB أو logs؛ hash مضبوط بخوارزمية مناسبة.
- unique active-code policy وexpiry/attempt counters.
- idempotency لإصدار الرمز وresult lookup بعد فقد الرد.
- notification delivery إن وجدت منفصلة عن حقيقة الرمز.
- audit يتضمن issuer/target/surface/reason دون raw code.

## الاختبارات

- issue لActor مفقود/معلق/wrong surface.
- concurrent issue/revoke/reissue.
- same idempotency key.
- raw-code scans للlogs والDB.
- expiry boundary وclock skew.
- copy modal ثم refresh.

## التجريب اليدوي

1. افتح Actor مؤهلًا من Control Panel.
2. أصدر رمزًا وانسخه، ثم أغلق modal وأعد الصفحة.
3. تحقق من masking وعدم وجود raw code في Network/logs بعد الاستجابة الأولى.
4. ألغِ الرمز وحاول استخدامه.
5. أعد الإصدار وتأكد من إبطال السابق.
6. نفّذ نقرًا مزدوجًا وفقد الرد ثم تحقق من النتيجة.
