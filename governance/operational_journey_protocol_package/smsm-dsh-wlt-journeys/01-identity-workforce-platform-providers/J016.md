# J016 — Progressive Rollout وKill Switch

```yaml
owner: Platform Control
actors: [OPERATOR, CUSTOMER, PARTNER, CAPTAIN, FIELD]
surfaces: [control-panel, app-client, app-partner, app-captain, app-field]
dependencies: [FOUNDATION-00, J015]
assessment_status: NOT_ASSESSED
closure_status: OPEN
```

## النتيجة التشغيلية

قرار rollout حتمي لنفس Actor/context عبر جميع الخدمات والأسطح، مع targeting/effective time/percentage وkill switch مركزي فوري، وصفر feature flags محلية موازية.

## الحالة الحالية

- يجب جرد كل flags/constants/env checks في المستودع.
- غير مثبت أن القرار deterministic وأن cache invalidation فوري.
- الخطر: نفس Actor يرى feature في Surface ولا يراه في آخر، أو kill switch يوقف UI فقط بينما Backend يستمر.
- المطلوب: decision contract/service، stable hashing، server enforcement، diagnostics.

## Control Panel

- قائمة capabilities/rollouts والحالة والtargets والنسخة.
- create/edit/schedule/pause/kill مع diff وapproval حسب J015.
- preview actor/partner/store decision دون منح صلاحية.
- metrics exposure مع حماية من bias/PII.

## التطبيقات

- navigation/control visibility تعتمد decision موثوقة.
- Backend يرفض command عند kill حتى لو UI stale.
- عند switch off أثناء الشاشة تظهر blocked state وتزال queued mutation.
- offline لا يفترض enabled إذا انتهت freshness لعملية خطرة.

## التقنية

- stable actor/context key وpercentage algorithm versioned.
- no random per request.
- decisions cached بTTL/version وinvalidated by event.
- kill switch fail-closed للقدرات الحساسة.
- flags لا تنقل financial truth أو authorization.

## الاختبارات

- نفس Actor عبر surfaces/services.
- boundaries 0/1/99/100%.
- start/end times.
- cache stale وevent loss.
- kill أثناء mutation.
- local flag grep/guard.

## التجريب اليدوي

1. فعّل capability لنطاق محدود.
2. افتحها عبر كل Surface لنفس Actors مختلفين.
3. غيّر النسبة والوقت.
4. نفّذ kill أثناء شاشة مفتوحة وoffline.
5. استدع API مباشرة بعد kill.
6. تحقق من عدم وجود flags محلية.

## الإغلاق

`local_feature_flags=0; inconsistent_decisions=0; backend_kill_enforcement=PASS; deterministic_targeting=PASS; stale_sensitive_actions=0; evidence_sha=CURRENT_SHA`.
