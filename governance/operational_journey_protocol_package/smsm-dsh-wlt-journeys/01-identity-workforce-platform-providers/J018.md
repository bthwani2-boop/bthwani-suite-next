# J018 — سجل المزودين والقدرات والصحة

```yaml
owner: Providers
actors: [OPERATOR, SERVICE_IDENTITY]
surfaces: [control-panel, app-client, app-partner, app-captain, app-field]
dependencies: [FOUNDATION-00, J017]
assessment_status: NOT_ASSESSED
closure_status: OPEN
```

## النتيجة التشغيلية

سجل مركزي لتعريف provider/capabilities/environment/health/maintenance/secret references، يستهلكه كل مجال دون نسخ إعدادات أو كشف أسرار.

## الحالة الحالية

- provider registry موجود مفهوميًا؛ يلزم مقارنة manifests/env/adapters/runtime compose.
- الخطر: إعداد مزود في أكثر من مكان، capability معلنة بلا adapter، secrets في DB/UI، health غير مرتبط بالاستخدام الفعلي.
- المطلوب: canonical registry وvalidation وruntime binding وmaintenance decision.

## Control Panel

- قائمة providers مع domain/capabilities/environment/status/last check.
- detail يعرض config metadata وsecret reference masked فقط.
- أزرار enable/disable/maintenance/test connection حسب permission/change-set.
- لا يسمح لصق secret خام إلا عبر قناة secrets المعتمدة إن وجدت.
- health failure يوضح القدرات والأسطح المتأثرة.

## التطبيقات

- لا ترى registry الداخلي.
- تعرض حالات provider unavailable/degraded على مستوى feature المعني.
- لا تحتوي API keys أو provider URLs الحاكمة.
- لا تتصل بالمزود مباشرة إلا capability مصرح بها معماريًا وبعقد آمن.

## التقنية

- manifest/version/capability schema.
- secret refs إلى secret store/env injection، لا response.
- adapter registration يتطابق مع registry.
- health/maintenance events وcache.
- WLT financial provider adapters تبقى داخل WLT.

## الاختبارات

- capability بلا adapter.
- missing secret ref.
- duplicate provider/environment.
- maintenance toggle.
- secret scans في bundle/logs/API.
- provider status stale.

## التجريب اليدوي

1. سجل provider صالحًا وآخر ناقص القدرة.
2. فعّل maintenance واختبر الأسطح المتأثرة.
3. احذف secret ref في بيئة اختبار.
4. شغّل test connection وراقب timeout/redaction.
5. افحص mobile/web bundles.
6. تحقق من WLT adapter isolation.

## الإغلاق

`scattered_provider_configs=0; capability_adapter_mismatch=0; secret_exposure=0; maintenance_propagation=PASS; provider_health_readback=PASS; evidence_sha=CURRENT_SHA`.
