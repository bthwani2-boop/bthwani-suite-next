## النتيجة التشغيلية النهائية

يدير DSH Cancellation State Machine وفق actor والحالة والسبب والسياسة، ويزيل/يوقف الآثار التشغيلية ذرّيًا أو عبر saga محكومة. WLT يملك refund/reversal الحقيقة المالية. كل Surface يقرأ status واحدة، ولا ينتج إلغاء مزدوج أو Refund مزدوج أو assignment شبح.

## تشخيص الحالة الحالية

### الموجود
- order cancellation handlers/screens وrefund finance bridge.
- order/assignment/custody/payment references.

### الناقص
- eligibility matrix حسب actor/order state/fulfillment/payment.
- request vs immediate cancellation distinction.
- approval/rejection reasons وdeadlines.
- saga steps لإلغاء assignment/notifications/WLT.
- unknown financial result وreconciliation.
- customer-facing fee/refund preview من WLT.

### الخاطئ أو الممنوع
- زر Cancel يغير state مباشرة بلا policy.
- DSH يحسب refund أو cancellation fee.
- cancellation بعد completion دون return/refund case.
- إعادة الطلب تنشئ refund إضافي.
- Captain يحتفظ assignment بعد cancellation.

### التصحيح المطلوب
- lifecycle `REQUESTED | UNDER_REVIEW | APPROVED | REJECTED | CANCELLING | CANCELLED | FINANCIAL_PENDING | RESOLVED`.
- command/idempotency/version/reasons.
- operational saga وWLT reference.
- generated eligibility/allowedActions.
- إزالة direct cancellation/refund shortcuts.

### الإضافات المطلوبة
- cancellation preview وconsequences.
- Control Panel case timeline/reconciliation.
- notification templates لكل actor.

## App Client

- Cancel يظهر فقط عند eligibility.
- reason selector، details، preview للنتيجة المالية من WLT facade، confirm، status tracking.
- حالات immediate/review required/not allowed/financial pending/unknown.
- لا يعرض `تم الاسترداد` قبل WLT readback.

## App Partner

- request notification، response/decision إذا policy، stop preparation actions.
- يرى reason المسموح والأثر التشغيلي.

## App Captain

- assignment removed/cancelled banner، navigation/actions disabled، data cleared.
- إذا custody موجودة يتلقى return/rescue instruction لا مجرد اختفاء.

## Control Panel

- cancellation queue، eligibility/policy، actor/reason، order/payment/assignment refs.
- controls approve/reject/reconcile/escalate حسب permission.
- لا إدخال refund amount داخل DSH.

## العقود والبيانات

- cancellation case/version/decision.
- unique active cancellation per order.
- saga checkpoints/outbox.
- WLT refund/reversal request idempotency/reference.
- order/assignment/custody transitions versioned.

## الاختبارات الآلية

- double cancel وmulti-actor race.
- cancel vs partner accept/pickup/completion.
- unauthorized actor/reason.
- WLT timeout/unknown/replay.
- assignment removal/custody handling.
- stale version.
- surface parity.

## التجريب اليدوي

1. ألغِ من Client قبل وبعد partner accept.
2. اختبر Partner/Operator decisions.
3. حاول أثناء assignment/pickup/completion.
4. افصل WLT بعد request.
5. كرر الطلب من عدة أجهزة.
6. راقب Captain/Partner/Client/Control Panel.
7. تحقق من WLT reference وعدم duplicate refund.
