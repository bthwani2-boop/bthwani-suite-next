## النتيجة التشغيلية النهائية

Ticket واحدة مرتبطة بالActor/Order/category، ورسائل مرتبة idempotent ومرفقات Media وSLA/claim. Notifications للتسليم فقط. لا cross-ticket IDOR أو internal note leakage أو message duplicates.

## التشخيص

- **الموجود:** support/message delivery handlers وrouters/workspace.
- **الناقص:** category/routing/priority، ticket/message states، claim/SLA، ordering/offline، attachment policy.
- **الخاطئ:** predictable IDs، Push truth، optimistic sent بلا correction، raw URL، impersonation.
- **التصحيح:** support aggregate، object auth، client_message_id، sequence، claim/version، visibility server-side.
- **الإضافة:** escalation، transcript export/redaction، canned response governance.
