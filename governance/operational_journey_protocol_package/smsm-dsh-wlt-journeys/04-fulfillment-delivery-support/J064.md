## النتيجة التشغيلية النهائية

يستقبل DSH نقاط موقع من الكابتن المرتبط بالassignment فقط، يتحقق من الزمن والدقة والسرعة والترتيب، ويعرض tracking projection محدودة الخصوصية. Provider يرسم/يوجه فقط. لا تُقرأ أو تكتب مواقع خارج الطلب، وتخضع retention والـoffline batches لقواعد صريحة.

## تشخيص الحالة الحالية

### الموجود
- dispatch live tracking handlers وmaps provider boundary.
- App Captain route وApp Client tracking وControl Panel monitor.

### الناقص
- location ingest contract وbatch semantics.
- integrity rules وreason codes.
- publish frequency/adaptive rate/battery policy.
- privacy visibility windows.
- retention/aggregation/deletion.
- stale/offline/degraded UI.

### الخاطئ أو الممنوع
- قبول location دون assignment/session binding.
- عرض raw trail كامل للعميل أو الشريك.
- out-of-order point يعيد marker للخلف.
- GPS spoof/zero accuracy بلا flag.
- raw coordinates في logs/analytics.

### التصحيح المطلوب
- signed/scoped ingest token أو strong auth binding.
- sequence/timestamp/accuracy validation.
- projection per active order مع coarse views حسب actor.
- provider adapter only.
- redaction وretention jobs وحراس telemetry.

### الإضافات المطلوبة
- integrity alerts وlocation gap incident.
- last-updated/stale badge.
- offline batch reconciliation وdedupe.

## App Captain

- location permission/readiness، publishing indicator، battery/network state.
- controls: enable location، retry، open settings، report GPS issue.
- offline queue bounded ومشفرة؛ يظهر pending/stale.
- لا يسمح publish بعد assignment revocation/completion.

## App Client

- marker/route/ETA التقريبي، last updated، stale/degraded banner.
- no exact historical trail.
- controls: refresh، contact/support وفق policy.

## App Partner

- tracking summary للطلب الخاص فقط، precision أقل حسب الحاجة.
- لا يرى موقع الكابتن خارج pickup/route relevant window.

## Control Panel

- live map، integrity flags، gaps، last point، accuracy، assignment refs.
- controls: refresh، open incident، no manual coordinate edit.
- historical access permission/audit.

## العقود والبيانات

- point schema: assignment/order/device/sequence/timestamp/lat/lon/accuracy.
- unique sequence/dedupe وordered processing.
- retention tiers؛ raw→aggregated→deleted.
- privacy projections per actor/state.
- provider route cache provenance.

## الاختبارات الآلية

- wrong assignment/captain writes.
- cross-order reads.
- stale/out-of-order/duplicate points.
- impossible speed/spoof/accuracy.
- offline batch replay.
- provider map down.
- post-completion access.
- telemetry coordinate leak scan.

## التجريب اليدوي

1. ابدأ Assignment وانشر مواقع حية.
2. افصل الشبكة وانشر batch ثم أعد الاتصال.
3. أرسل نقاطًا قديمة/مكررة/بعيدة بصورة غير منطقية.
4. ألغِ/reassign أثناء النشر.
5. قارن precision على Client/Partner/Control Panel.
6. عطّل map provider.
7. تحقق من retention والlogs بعد completion.
