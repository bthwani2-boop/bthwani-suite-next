## النتيجة التشغيلية النهائية

يدير DSH Return Case مرتبطة بالOrder/items/evidence/window/decision/logistics، ثم يطلب Refund من WLT. لا Surface ينفذ Refund أو يحدد المبلغ، ولا case تُغلق قبل اكتمال return/financial result المطلوب.

## التشخيص

- **الموجود:** refunds handlers/WLT contracts/Media/support.
- **الناقص:** eligibility/item rules، case lifecycle، evidence، logistics، partial return، financial reconciliation.
- **الخاطئ:** direct WLT call، amount input، multiple active cases، orphan evidence، resolve before result.
- **التصحيح:** versioned case/items/decisions، Media refs، WLT idempotency، logistics/custody records.
- **الإضافة:** return pickup/dropoff، SLA، partner response، reconciliation queue.
