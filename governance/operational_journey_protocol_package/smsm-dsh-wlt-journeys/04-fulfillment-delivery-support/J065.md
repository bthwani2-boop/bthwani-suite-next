## النتيجة التشغيلية النهائية

تنتقل الحيازة من Store إلى Captain مرة واحدة بعد جاهزية Order والتحقق من Store/Captain/Assignment/Proof. Order وAssignment وCustody تتغير ذرّيًا، ولا Pickup قبل READY أو بproof معاد.

## التشخيص

- **الموجود:** handoff contract وPartner/Captain contexts.
- **الناقص:** custody state machine، proof policy، arrival/wait، package condition، exception/override.
- **الخاطئ:** pickup من Store/Captain خاطئ، code replay، partner complete بلا captain proof، معاملات منفصلة.
- **التصحيح:** custody command واحد، proof hash/expiry، locks/versions، exception commands.
- **الإضافة:** SLA/wait، package checklist، handoff workbench.
