## النتيجة التشغيلية النهائية

يدير الشريك التجهيز بتقدير جاهزية versioned، ويبلغ عن نقص أو تأخير أو استبدال. أي تغيير للسعر أو الالتزام يمر عبر DSH orchestration وWLT، ويحتاج موافقة العميل حسب السياسة؛ لا تعديل صامت لخطوط الطلب.

## التشخيص

- **الموجود:** preparation handlers/screens/issues وWLT boundaries.
- **الناقص:** state machine، ETA bounds، issue taxonomy، proposal/decision timeout، partial replacement، financial adjustment.
- **الخاطئ:** direct Order line edit، فرق سعر محلي، READY مع issue مفتوحة، ETA free-text بلا audit.
- **التصحيح:** commands start/update-estimate/report-issue/propose/decide/resolve/ready، immutable proposal versions، WLT adjustment refs.
- **الإضافة:** customer decision UI، issue queue، evidence requirements، SLA alerts.

## الأسطح

- App Partner: Start Preparation، ETA ضمن bounds، Report Issue، item/reason/evidence، replacement، Ready gate.
- App Client: preparation status/ETA، proposal detail/price impact، Accept/Reject، expiry/readback.
