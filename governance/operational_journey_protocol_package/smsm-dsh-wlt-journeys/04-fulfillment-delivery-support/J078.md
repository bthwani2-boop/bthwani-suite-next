## النتيجة التشغيلية النهائية

تبني DSH projections تحليلية من الأحداث التشغيلية committed، مع تعريفات metric/SLA/version/timezone/grain واضحة. Control Panel يعرض المؤشرات والتنبيهات القابلة للتفسير، وApp Partner يرى subset scoped. التحليلات ليست مصدر حقيقة ولا تنفذ transitions أو أرقام مالية WLT-owned.

## تشخيص الحالة الحالية

### الموجود
- operational analytics handlers/screens وSLA alerts.
- order/preparation/pickup/delivery/support events.

### الناقص
- metric registry وتعريف numerator/denominator/window/timezone.
- SLA clock pause/resume/exclusions.
- projection checkpoints/backfill/rebuild.
- freshness/quality indicators.
- alert dedupe/ack/escalation.
- partner scope/privacy/minimum sample.

### الخاطئ أو الممنوع
- KPI محسوب في UI أو SQL متفرق بلا تعريف.
- رقم مالي أو settlement مشتق خارج WLT.
- تنبيه يغير Order مباشرة.
- dashboard لا يوضح freshness/partial data.
- partner يرى بيانات متجر/شريك آخر أو samples صغيرة حساسة.

### التصحيح المطلوب
- metric/SLA registry versioned.
- analytics pipeline/projection rebuildable.
- server-side filters/time ranges/export.
- alert lifecycle منفصل عن domain commands.
- إزالة duplicated dashboards/queries/constants.

### الإضافات المطلوبة
- data quality/lag panels.
- drill-down إلى records المالكة بصلاحية.
- audit للexports والتنبيهات الحساسة.

## Control Panel

- dashboards: order funnel، partner response، preparation، dispatch، pickup، delivery، exceptions، support SLA.
- controls: time range، timezone، filters، compare، drill-down، export، acknowledge/escalate alert.
- كل chart يوضح definition/version/freshness/sample/empty/error.
- no action button يغير الحقيقة إلا فتح workflow مالك المجال.

## App Partner

- store-scoped performance، trends، SLA breaches المسموحة، actionable links.
- لا platform-wide competitor data أو sensitive sample.
- نفس metric definitions مع scope مختلف.

## العقود والبيانات

- metric registry IDs/versions/formulas as governed config.
- projection tables/checkpoints/event versions.
- SLA instances/pauses/breaches.
- alert instances/dedupe/ack/escalation.
- export jobs/scoped access/retention.

## الاختبارات الآلية

- metric golden datasets.
- timezone/window boundaries.
- duplicate/out-of-order event.
- projection rebuild/backfill parity.
- SLA pause/resume.
- alert dedupe/escalation.
- partner isolation/minimum sample.
- no WLT financial truth duplication.

## التجريب اليدوي

1. نفّذ Orders تغطي success/failure/timeout والاستثناءات.
2. قارن dashboard مع records المصدر.
3. بدّل ranges/timezones/filters وكل chart.
4. أوقف consumer ثم backfill/rebuild.
5. اختبر SLA pause/breach/alert ack/escalation.
6. افتح Partner analytics لشريكين.
7. اختبر export والصلاحيات/freshness/empty/error states.
