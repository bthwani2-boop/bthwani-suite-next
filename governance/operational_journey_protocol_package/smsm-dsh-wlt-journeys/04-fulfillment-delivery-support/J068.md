## النتيجة التشغيلية النهائية

تُلتقط صور/توقيع/وثائق إثبات التسليم عبر Media runtime، وتُربط في DSH بالorder/proof set والمالك والحالة. تخضع للنوع والحجم والفحص والmetadata والاحتفاظ، ولا تستخدم raw public URLs أو ملفات orphan. App Client يرى فقط ما يسمح به Product Truth.

## تشخيص الحالة الحالية

### الموجود
- shared media runtime وpresigned/resumable uploads.
- delivery proof media handlers/contracts.

### الناقص
- evidence media policy حسب النوع.
- ownership binding قبل finalize.
- malware/content scan states.
- retention/legal hold/cleanup.
- inaccessible/expired URL UX.
- signature-specific integrity.

### الخاطئ أو الممنوع
- base64 أو file path داخل DSH records.
- public permanent URL.
- finalize upload لطلب/Actor آخر.
- قبول file قبل scan أو نوع spoofed.
- حذف media بينما proof retained أو بقاء orphan.

### التصحيح المطلوب
- upload intent scoped to order/proof/type/actor.
- server-side MIME/content/size checks.
- states `UPLOADING | QUARANTINED | SCANNING | READY | REJECTED | EXPIRED | DELETED`.
- DSH references immutable IDs فقط.
- cleanup/reconciliation jobs.

### الإضافات المطلوبة
- capture guidance/quality checks.
- retry/resume/offline support.
- Control Panel secure viewer مع watermark/audit.

## App Captain

- capture/select according to policy، preview، retake، upload progress، resume، remove قبل submit.
- يمنع submit حتى required media READY.
- حالات permission denied، file too large، scan rejected، upload expired، offline queued.

## Control Panel

- secure evidence viewer، metadata، scan result، owner/order/proof refs، retention.
- access permission/audit، no raw URL copy.
- controls: request replacement، quarantine/escalate، legal hold حسب policy.

## App Client

- يعرض proof summary أو media subset فقط إذا Product Truth يسمح.
- signed short-lived access وfallback إذا غير متاح.

## العقود والبيانات

- media intent/finalize/read contracts.
- DSH proof_media join unique binding.
- content hash/dedupe policy دون cross-actor leakage.
- retention timestamps/legal hold.
- audit لكل view/download.

## الاختبارات الآلية

- malicious/oversized/MIME spoof.
- wrong order/actor binding.
- duplicate/resume upload.
- expired signed URL.
- scan timeout/rejection.
- cleanup failure/orphan detection.
- unauthorized viewer.

## التجريب اليدوي

1. التقط كل نوع evidence مطلوب.
2. اقطع الشبكة واستأنف upload.
3. ارفع ملفًا كبيرًا/نوعًا خاطئًا/ضارًا.
4. حاول binding لOrder آخر.
5. افتح viewer بصلاحيات مختلفة.
6. انتظر URL expiry وجدد الوصول.
7. شغّل cleanup/reconciliation وافحص orphans.
