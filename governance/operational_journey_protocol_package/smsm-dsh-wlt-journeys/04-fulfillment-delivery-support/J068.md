## النتيجة التشغيلية النهائية

تُلتقط وسائط PoD عبر Media intent scoped للOrder/proof/type/actor، وتخضع للscan والretention. DSH يخزن media IDs وروابط proof فقط؛ لا base64 أو URL عام أو orphan.

## التشخيص

- **الموجود:** Media runtime/resumable upload وPoD handlers.
- **الناقص:** purpose policy، binding قبل finalize، scan states، retention/legal hold، secure viewer.
- **الخاطئ:** public URL، wrong-order binding، active-before-scan، delete breaks evidence.
- **التصحيح:** scoped intent، MIME/content checks، lifecycle، immutable join، cleanup/reconciliation.
- **الإضافة:** capture quality، resume، watermark/view audit.
