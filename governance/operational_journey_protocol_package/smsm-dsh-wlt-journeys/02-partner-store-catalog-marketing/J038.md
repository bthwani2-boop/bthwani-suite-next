## النتيجة التشغيلية

Home feed مركزي composed حسب location/serviceability/publication/catalog/campaign/rollout، بترتيب وpagination حتميين، دون fixtures أو content blocks محلية في App Client.

## الحالة الحالية

- Home discovery endpoint/runtime readback موجود لكنه فشل سابقًا عند صفر stores قبل bootstrap fix.
- الخطر: static home JSON، duplicate sections، unpublished store، stale campaign، local category/reel lists، false empty.
- المطلوب: composer/read model، source lineage، freshness، invalidation، degraded strategy.

## Control Panel

- home composition/preview حسب location/actor/rollout.
- sections: stores/categories/campaigns/reels/recommendations حسب Product Truth.
- controls: schedule/order/enable/disable عبر change sets.
- preview يعرض مصدر كل item وسبب الاستبعاد.
- لا manual IDs بلا validation للpublication/serviceability.

## App Client

- Home route بعد address/readiness.
- pull-to-refresh وpagination بلا duplicates.
- cards/actions: open store/category/product/campaign/reel.
- حالات مستقلة: no address، no service، no content، stale cached، partial section failure، full outage.
- لا يعرض fixture عند صفر data؛ يعرض empty حقيقي مع next action.

## التقنية

- feed items typed وstable IDs/cursors.
- compose from canonical projections.
- rollout/policy versions.
- cache scoped by location/context/version.
- partial failure envelope إذا معتمد.
- runtime seed classification واضحة؛ dev seed ليس production fallback.

## الاختبارات

- zero stores/categories/products.
- unpublished/paused stores.
- duplicate cursor pages.
- stale cache/invalidation loss.
- section provider failure.
- rollout targeting consistency.
- section-by-section source lineage and control binding.

## التجريب اليدوي

1. شغّل clean bootstrap وتحقق من Dashboard readback غير صفري في dev profile.
2. اختبر موقعًا بلا تغطية وPreview في Marketing.
3. أوقف Store/Campaign/Product أثناء Home مفتوح وراقب الأقسام المالكة.
4. عطّل composer/index consumer من Platform.
5. كرر pagination/refresh.
6. افحص Analytics وNetwork والsource IDs وعدم fixtures.
