## النتيجة التشغيلية

Media يملك الملف والscan/storage/URL lifecycle؛ DSH يملك ربط الأصل بالمنتج والغرض والترتيب والحالة. لا raw public URLs أو unscanned active media أو orphan assets.

## الحالة الحالية

- media service/minio/runtime موجودة؛ ownership/link lifecycle غير مثبت كاملًا.
- الخطر: upload مباشر غير موقع، URL دائم، MIME spoof، asset active قبل scan، delete product يترك orphan، local image fixture.
- المطلوب: upload intent/complete/scan/approve/link contracts وcleanup jobs.

## Control Panel

- media tab: thumbnails/status/order/alt text/owner/upload time.
- controls: upload، replace، reorder، set primary، edit alt text، remove، review rejection.
- scanning/quarantined/rejected states واضحة.
- preview يستخدم signed/CDN URL قصيرة العمر.

Marketing يستهلك approved media refs في حملاته ولا يملك الأصل؛ App Client يعرض active approved فقط.

## App Partner/App Field

- resumable upload progress وretry/cancel.
- capture/select/crop إن كان معتمدًا، مع size/type validation أولي غير حاكم.
- لا يعتبر الرفع مكتملًا قبل server complete+scan.
- offline draft يحتفظ reference مؤقتًا وآمنًا.

## App Client

- يعرض active approved media فقط.
- placeholder/fallback تصميمي لا fixture حقيقي.
- broken/expired URL يعاد جلبها لا تخزن دائمًا.
- alt text/accessibility.

## التقنية

- upload intent scoped وshort-lived.
- MIME/content scan/hash/dedup.
- ownership/link constraints.
- lifecycle `PENDING_UPLOAD→SCANNING→ACTIVE|REJECTED→EXPIRED/DELETED`.
- retention/orphan cleanup.
- no blob in DSH DB.

## الاختبارات

- MIME spoof/large file/bomb/path traversal.
- interrupted/duplicate upload.
- wrong owner/product link.
- scan failure.
- delete/merge product cleanup.
- expired URL rendering.
- all section viewers and actions enforce owner/purpose.

## التجريب اليدوي

1. ارفع صورًا صالحة وغير صالحة من Catalogs/Partner/Field.
2. اقطع upload ثم استأنفه.
3. حاول ربط asset بمنتج آخر.
4. reorder/set primary واحذف المنتج.
5. افتح Operations/Client بعد expiry URL.
6. افحص Platform storage/DB/jobs/logs.
