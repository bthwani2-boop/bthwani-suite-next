## النتيجة التشغيلية النهائية

تعمل المنظومة الفعلية عبر profiles المطلوبة وبترتيب dependencies ومهاجرات/seed/readiness صحيحة، مع BFF ومداخل الويب والموبايل والdeep links والجلسات. لا hidden local dependency ولا false-ready ولا port/config drift. النجاح Runtime مثبت على SHA نفسه ولا يعني Production authorization.

## تشخيص الحالة الحالية

### الموجود
- compose runtime profiles وscripts وExpo/Next entrypoints.
- health/readiness ومهاجرات/seed وruntime smoke.

### الناقص
- profile dependency graph موثق.
- cold-start/restart/dependency-loss matrix.
- config/secret validation fail-closed.
- BFF/session/deep-link parity.
- mobile export/build proof لكل app.
- all Control Panel routes runtime crawl.

### الخاطئ أو الممنوع
- service healthy قبل DB/migrations/dependencies.
- runtime up بلا seed ثم smoke يتوقع data.
- direct service URLs مختلفة بين shells.
- port collisions/legacy ports.
- صفحة Control Panel غير قابلة للبناء أو route dead.

### التصحيح المطلوب
- governed runtime phases: migrate→seed→start→readiness→smoke.
- dependency-aware readiness.
- config schema وsingle base URLs.
- route/deep-link registries.
- remove obsolete scripts/ports/fallbacks.

### الإضافات المطلوبة
- automated crawl لكل Control Panel section/page.
- mobile export/start smoke لكل app.
- restart/recovery evidence.

## جميع الأسطح

- App Client/Partner/Captain/Field: boot/session/deep links/API binding/offline reconnect.
- Control Panel: login/shell/navigation/all routes/BFF/session/error boundaries.

## Control Panel — عدم تجاهل أي قسم

يجب runtime-crawl لكل route مسجل في: Dashboard، Partners، Stores، Catalogs، Marketing، Operations، Support، HR، Platform/Policies/Providers، Analytics، WLT Finance، Audit/Administration. كل route يثبت loading/ready/empty/error/forbidden وارتباطه بالbackend الحقيقي.

## الاختبارات الآلية

- cold start/restart/graceful shutdown.
- dependency loss/recovery.
- missing/invalid config/secret.
- migration/seed/readiness order.
- port collision/legacy URL scan.
- mobile export/deep links.
- Control Panel route crawl/build.
- BFF/session authorization.
