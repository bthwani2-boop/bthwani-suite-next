## النتيجة التشغيلية النهائية

التشغيل المحلي وCI والبناء والإصدار يستخدمان manifests وports وprofiles وعقود Runtime واحدة. Control Panel يتصل عبر BFF المصرح، التطبيقات عبر resolvers والعملاء المولدين، والخدمات لا تُكشف بمداخل عشوائية. readiness تمنع mutations عند عدم الجاهزية، وhealth لا يزعم سلامة الاعتماديات.

## تشخيص الحالة الحالية

### الموجود
- Docker runtime موحد، ports جديدة، BFF، Expo runtimes، health/readiness، CI Runtime proof.

### الناقص
- topology/port/profile registry نهائي، parity بين local/CI/release، build provenance، config validation، failure-mode tests لكل Surface.

### الخاطئ
- legacy ports، direct service URLs في UI، env fallbacks، default secrets خارج local، health-only routing، mutable build inputs، route/BFF bypass.

### التصحيح
- runtime manifest حاكم، config schema/fail-fast، BFF allowlist، service discovery، immutable build metadata، bootstrap/readback لكل profile.
