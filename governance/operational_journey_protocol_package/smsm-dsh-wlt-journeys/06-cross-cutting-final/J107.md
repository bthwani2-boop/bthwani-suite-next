## النتيجة التشغيلية النهائية

لا تُغلق الحزمة لأن الملفات مكتوبة أو لأن اختبارًا منفردًا نجح. الإغلاق يتطلب على SHA نهائي واحد: مصادر حقيقة موحدة، عقود وعملاء مولدين، قواعد بيانات سليمة، Runtime فعلي، جميع الرحلات والشرائح والأسطح والتحكمات مختبرة، الأمن والمالية والخصوصية مثبتة، البقايا والخطط المتعارضة محذوفة، وCI كامل أخضر مع أدلة قابلة للتدقيق. كل نقطة غير مثبتة تبقى `OPEN` أو `UNPROVEN`.

## تشخيص ما يجب إثباته قبل الإغلاق

### الموجود المطلوب جرده
- 107 ملفات رحلة، ملفات رؤية الأسطح، سجل أقسام لوحة التحكم، Journey Gate، العقود والخدمات والاختبارات وRuntime profiles.

### الناقص الذي يمنع الإغلاق
- أي رحلة بلا تشخيص أو شرائح أو Surface behavior أو manual acceptance.
- أي قسم/Route/تبويب/زر/أيقونة/حالة بلا mapping واختبار.
- أي CI failure أو skipped gate مطلوب أو runtime proof غير منفذ.
- أي مصدر حقيقة أو contract/type/status/permission/policy موازٍ.

### الخاطئ أو الممنوع
- ادعاء 100% دون أدلة Same-SHA.
- إغلاق وثائقي دون تنفيذ كود أو Runtime.
- allowlist أو skip أو fallback يخفي فشلًا.
- إبقاء ملفات old/backup/copy/trash داخل المسارات الحية.
- merge بينما PR draft أو Journey/CI مفتوح.

### التصحيح والإضافات
- Evidence index آلي، coverage guard، immutable diff، stale-doc detector، dead-file/route/import scan، final runtime/manual checklist، signed closure decision.
