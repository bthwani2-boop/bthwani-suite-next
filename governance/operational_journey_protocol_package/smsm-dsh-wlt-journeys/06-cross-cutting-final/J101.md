## النتيجة التشغيلية النهائية

تعمل التطبيقات بوضوح عند فقد الشبكة دون ادعاء نجاح أو إبقاء صلاحيات منتهية. البيانات المحلية Cache مشتقة ومقسمة حسب Actor، والأوامر المؤجلة مسجلة بالنسخة والوقت والـidempotency وتُعاد المصادقة والتفويض والتحقق عند reconnect. التعارض لا يُحل بـlast-write-wins صامت.

## التشخيص

- **الموجود:** local storage/offline patterns وتطبيقات Expo متعددة.
- **الناقص:** offline capability matrix لكل feature، queue protocol، limits، encryption، expiry، conflict UX، diagnostics.
- **الخاطئ:** queued privileged action بعد revoke، نجاح وهمي، تسرب cache بين الحسابات، replay بعد order/task completion، تخزين PII زائد.
- **التصحيح:** controller موحد، partitioned encrypted cache، ordered commands، server revalidation، conflict/result lookup.

## مصفوفة الميزات في التطبيقات

| Surface | مسموح Offline | ممنوع أو يحتاج اتصال | ما يجب أن يظهر |
| --- | --- | --- | --- |
| App Client | قراءة catalog/order/cart snapshot وdraft address/support message وفق policy | checkout confirm/payment/refund وأي قرار منتهي | stale timestamp، pending badge، sync/conflict sheet |
| App Partner | قراءة orders/catalog/inventory snapshot وdraft evidence | accept/reject/publish/price/stock command بلا revalidation | current scope/version وpending queue |
| App Captain | route/task snapshot وproof draft | accept offer/availability/handoff/completion بعد expiry أو revoke | connectivity banner، action expired/conflict |
| App Field | assigned work/evidence draft | cross-scope mutation أو انتهى assignment/shift | assignment freshness وblocked reason |

## العقود والبيانات

- command: id/type/base_version/idempotency/created_at/expires_at/scope/payload schema version.
- لا raw tokens أو PII زائدة في queue.
- reconnect sequence: session validate → permissions/scope/readiness → fetch truth → classify commands → apply/reject/conflict → readback.
- logout/account switch يمسح partition المناسب ويوقف workers القديمة.

## الاختبارات الآلية

- airplane mode، app kill/reinstall، clock skew، queue overflow، duplicate reconnect، Actor switch، revoke أثناء offline، state completion قبل replay، schema upgrade، corrupted local storage.
- queue ordering/dedupe/expiry وencrypted partition cleanup وserver reauthorization.

3. أعد الاتصال وراقب conflict/rejection/readback دون نجاح كاذب أو Replay مكرر.
4. وثّق الفيديو وNetwork وDB/Audit لكل سيناريو.
