## النتيجة التشغيلية النهائية

كل ملف يمر عبر upload intent محدد الغرض والمالك، ثم upload/scan/quarantine/finalize/link/read/retention/delete. Media يملك الملف والmetadata، والمجال يملك الرابط والغرض فقط. لا raw public object ولا active unscanned media ولا orphan file/link.

## تشخيص الحالة الحالية

### الموجود
- shared media runtime وpresigned/resumable uploads.
- استخدامات catalog/HR/PoD/support.

### الناقص
- media-purpose registry.
- MIME/size/hash/scan policy لكل غرض.
- owner/link authorization.
- retention/legal hold/delete/restore.
- interrupted upload cleanup.
- secure viewer/download audit.

### الخاطئ أو الممنوع
- public permanent URL.
- path أو base64 داخل domain DB.
- finalize أو read لActor/object آخر.
- file active قبل scan.
- حذف owner يترك orphan أو يحذف evidence المطلوبة.

### التصحيح المطلوب
- upload intent scoped والغرض versioned.
- Media state machine.
- domain link table with immutable media ID.
- cleanup/reconciliation jobs.
- short-lived read URLs وaudit.

### الإضافات المطلوبة
- quarantine/review workflow.
- image/document quality validation.
- legal hold/retention diagnostics.

## التطبيقات

- capture/select/preview/progress/resume/cancel/retry.
- permission denied/file invalid/scan pending/rejected/expired states.
- لا success قبل READY + domain link readback.

## Control Panel — الأقسام

- Catalogs/Marketing: assets وpublication readiness.
- HR: documents/photos وaccess masking.
- Operations: PoD evidence.
- Support: attachments.
- Partners: logos/documents.
- Platform: media policy/health.
- Audit: كل view/download/delete/hold.

## الاختبارات الآلية

- path traversal/MIME spoof/oversized/bomb/malware.
- unauthorized read/link/finalize.
- interrupted/resumed upload.
- expired URL.
- deleted owner/legal hold.
- orphan cleanup/reconciliation.
- Control Panel secure viewer permissions.

## التجريب اليدوي

1. ارفع كل نوع ملف من كل Surface معتمد.
2. اقطع upload واستأنفه.
3. اختبر ملفًا ضارًا/كبيرًا/مزور النوع.
4. حاول ربطه بكائن آخر.
5. افتح viewers في أقسام Control Panel المختلفة.
6. اختبر delete/retention/legal hold.
7. شغّل reconciliation وافحص orphans.
