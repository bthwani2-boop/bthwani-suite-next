## النتيجة التشغيلية النهائية

Cache وSearch وRead Models مشتقات قابلة لإعادة البناء، مفاتيحها scoped/versioned ولها TTL/freshness/invalidation/reconciliation. لا تحتوي حقيقة قابلة للكتابة أو permissions قديمة أو بيانات تتسرب بين Actor/Partner/Store/Operator Context.

## تشخيص الحالة الحالية

### الموجود
- discovery/catalog/order/analytics projections وfrontend caches.
- search/filter surfaces متعددة.

### الناقص
- cache/search registry لكل dataset/owner/source/TTL/key/invalidation.
- scoped key standards.
- stampede protection وnegative cache.
- rebuild/checkpoint/reconciliation.
- stale behavior UI.
- permission/state invalidation.

### الخاطئ أو الممنوع
- cache/search writable authority.
- key لا يتضمن actor/context/store/version.
- permission revoked لكن cache تعرض البيانات.
- rebuild أثناء traffic ينتج فقد أو duplicate.
- UI لا يوضح stale/partial.

### التصحيح المطلوب
- registry وkey schema.
- source events/invalidation/reconciliation.
- safe fallback عند cache/search outage.
- stale metadata في contracts.
- إزالة local hardcoded searchable datasets.

### الإضافات المطلوبة
- Control Panel freshness/index diagnostics لكل قسم.
- rebuild/compare tools مع dry-run.
- cache bleed negative suite.

## جميع الأسطح

- cache محلية read-through فقط مع `as_of/version`.
- privileged actions تعيد authorization من الخادم.
- stale state واضح ويمنع mutations التي تعتمد حقيقة منتهية.

## Control Panel — كل الأقسام

- Dashboard/Analytics تعرض freshness.
- Partners/Stores/Catalogs/Marketing تعيد invalidation بعد mutations.
- Operations/Support/HR/Finance تمنع cross-context cached data.
- Platform يملك policy لا data override.
- كل section يملك index/rebuild diagnostics أو يثبت N/A.

## الاختبارات الآلية

- cross-partner/actor/context cache bleed.
- stale permission/state.
- missing invalidation.
- cache/search outage.
- stampede/load.
- rebuild during traffic.
- pagination/index parity.
- local dataset scan.

## التجريب اليدوي

1. غيّر بيانات في كل قسم ثم راقب invalidation.
2. اسحب صلاحية/انقل store/context مع cache دافئة.
3. عطّل cache/search.
4. شغّل rebuild أثناء traffic.
5. راقب stale/freshness على التطبيقات وكل أقسام Control Panel.
6. قارن source truth مع index.
