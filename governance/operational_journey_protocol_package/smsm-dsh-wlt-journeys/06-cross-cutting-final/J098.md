## النتيجة التشغيلية النهائية

كل Job مؤجلة تملك هوية وowner وqueue وlease/heartbeat/timeout/retry/backoff/dedupe/cancellation/DLQ وسياسة replay. لا job مفقودة أو عالقة بلا SLA، ولا side effect مكرر، ولا زر Replay غير مصرح ومدقق.

## تشخيص الحالة الحالية

### الموجود
- workers/jobs للمهاجرات والتنبيهات والمصالحة والـtimeouts والprojections.
- CI/Runtime scripts لتشغيل الخدمات.

### الناقص
- job registry شامل.
- lease/heartbeat/visibility semantics موحدة.
- retry categories/backoff/jitter/max attempts.
- DLQ ownership/runbook.
- queue health/readiness/metrics.
- operator replay safety.

### الخاطئ أو الممنوع
- cron/job بلا owner أو idempotency.
- worker crash يترك lock دائمًا.
- retry لكل الأخطاء بنفس السياسة.
- replay payload من UI بلا validation.
- DLQ تُستخدم كأرشيف منسي.

### التصحيح المطلوب
- job registry وcommon envelope.
- atomic claim/lease/heartbeat.
- error classification وbounded retry.
- DLQ with reason/owner/next action.
- replay command يجري eligibility/idempotency checks.

### الإضافات المطلوبة
- queue dashboards وSLA alerts.
- stuck-job recovery.
- clock drift/queue outage tests.

## Control Panel

- Operations: queues/jobs/leases/stuck/retries.
- Platform: schedules/config/owners.
- Finance: financial jobs read-only/reconcile actions governed.
- Support: incident/escalation links.
- Analytics: throughput/failure/SLA metrics.
- Audit: cancel/replay/requeue actor/reason/result.

## الاختبارات الآلية

- worker crash before/after effect.
- duplicate lease/heartbeat expiry.
- retry exhaustion.
- malformed/poison payload.
- queue unavailable.
- clock drift.
- replay twice.
- unauthorized operator action.

## التجريب اليدوي

1. أوقف worker أثناء job.
2. نفّذ retryable وغير retryable failures.
3. املأ DLQ بpayload تجريبية.
4. جرّب replay/cancel من أدوار مختلفة.
5. عطّل queue ثم أعدها.
6. راقب كل أقسام Control Panel المتأثرة.
