# سجل تغطية لوحة التحكم

هذا المجلد هو السجل التنفيذي المشتق للسطح `control-panel` داخل حزمة رحلات SMSM. لا يعلو على Product Truth أو OpenAPI أو كود Runtime، لكنه يمنع تجاهل أي قسم أو Route أثناء تشخيص الرحلات وتنفيذها.

## مصدر الحقيقة الذي يقارن به السجل

- الملاحة الحية: `services/dsh/frontend/control-panel/navigation.ts`.
- صفحات Next الحية: `apps/control-panel/runtime/src/app/**/page.tsx`.
- الرؤية النهائية: `../07-final-surface-vision/CONTROL-PANEL-FINAL-VISION.md`.
- الرحلات: `J001..J107` داخل المجلدات الستة.

## ما يفرضه السجل

لكل قسم:

1. معرف وقيمة ملاحة ومسار رئيسي.
2. كل Routes الحالية بما فيها الديناميكية والفرعية.
3. الغرض والقدرات التي يجب أن توجد في النهاية.
4. الرحلات التي تغطي القسم.
5. حالات العرض الإلزامية.
6. أصناف التحكمات الإلزامية.
7. سيناريوهات التجريب اليدوي.

الحارس `tools/scripts/check-smsm-journey-coverage.mjs` يفشل عند:

- نقص أو تكرار رحلة من `J001..J107`.
- بقاء ملف رحلة مختصرًا أو بلا تشخيص الموجود/الناقص/الخاطئ/التصحيح/الإضافات/الاختبارات/التجريب اليدوي/الإغلاق.
- اختلاف أقسام الملاحة الحية عن السجل.
- وجود صفحة Next غير مسجلة أو Route مسجلة بلا صفحة.
- غياب أي قسم أو Route أو رحلة عن التغطية.
- نقص حالات العرض أو أصناف التحكمات أو سيناريوهات الاختبار الحاكمة.

نجاح الحارس يثبت اكتمال البنية الوثائقية فقط، ولا يثبت أن رحلة أو زرًا يعمل في Runtime.
