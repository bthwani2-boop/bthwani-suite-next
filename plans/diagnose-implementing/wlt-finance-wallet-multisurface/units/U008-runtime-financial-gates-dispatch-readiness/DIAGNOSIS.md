# U008 Diagnosis — Runtime Financial Gates, Provider and Dispatch Readiness

Financial code is not end-to-end executable if runtime gating blocks every mutation. Historical U002 evidence found the WLT API router wired with a nil wallet DecisionService, causing fail-closed mutation rejection before provider flows. That is package-level scope and must be fixed with a governed decision dependency, never bypassed. Provider mode must prove mock/simulator is non-production only and ambiguous external results reconcile before another mutation. Dispatch financial eligibility is WLT-owned because it reads captain wallet/policy; after U006 it must consume canonical wallet projection, trusted context and bounded TTL, while DSH consumes the opaque decision and never recalculates finance. DSH financial retry/outbox must retain stable idempotency/correlation and converge exactly once across timeout/restart.
