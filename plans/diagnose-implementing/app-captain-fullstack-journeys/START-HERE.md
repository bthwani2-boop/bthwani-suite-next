## Scope test

A path is in scope only when current source or Product Truth proves that it is reachable from `app-captain`, authenticates/provisions/gates the Captain, writes or reads canonical Captain state, is an authorized cross-surface writer/readback required to prove that same Captain result, or is runtime/native/security/build/test infrastructure directly required by a Captain capability. Everything else stays outside. Shared proximity, a red global job or a similar actor is insufficient.

`app-field` is outside unless a Captain change demonstrably alters a shared contract consumed by field; then only that shared impact is verified. Generic analytics, catalogs, dashboard, login and marketing remain excluded unless a direct Captain trace is later proven.
