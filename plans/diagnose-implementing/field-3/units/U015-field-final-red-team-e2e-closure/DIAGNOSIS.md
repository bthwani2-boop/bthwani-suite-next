# U015 — field-final-red-team-e2e-closure

هذه وحدة الإغلاق وليست rerun شكليًا. بعد اكتمال كل الوحدات يعاد حل `BB` ويثبت Final Candidate SHA؛ أي write بعده يبطل الأدلة المتأثرة ويعيد الدورة. يجب تنفيذ Final Cleanup + Hardening + Red-Team Review + End-to-End Verification على نفس الرأس، والبحث المتعمد عن عيب لا انتظار failure ظاهر. النجاح الجزئي لا يكفي: build/lint/typecheck/unit tests لا يثبتون runtime أو object auth أو DB أو cross-surface. يجب عدم وجود مشكلة معلومة قابلة للتنفيذ داخل النطاق.

المصفوفة النهائية تشمل: install/OpenAPI؛ package strict/closure validator؛ app-field typecheck/lint/tests/build؛ DSH/WLT/Identity/Workforce affected backend/database/migrations/contracts؛ security/isolation؛ Android real-device cold start/login/logout/restart/deep-links/online/offline/reconnect/notifications/image/document/location/maps/accessibility؛ assignment→draft→documents→review/collaboration→visit/readiness→catalog→publication؛ same-store Partner/Client readback؛ Finance provisioning/full/specified/unknown reconciliation؛ Native rebuilt artifact. لوحة التحكم تُفحص صفحة وتبويبًا ومكونًا لكل HR/Partners/Operations/Catalogs/Support/Finance جزء له ارتباط مثبت، مع تأكيد أن الأقسام العامة المستبعدة لم تُسحب إلى التنفيذ.

app-captain لا يدخل إلا shared payout regression؛ app-client لا يدخل إلا public readback؛ app-partner لا يدخل إلا onboarding/readiness/catalog/readback/shared payout. الإغلاق النهائي يتطلب RESULT لكل وحدة على candidate صالح، current CI/scanners applicable، وعدم وجود dead/duplicate/stale path ميداني أو deprecation confirmed غير منفذ. إذا تعذر إثبات بند فهو OPEN.
