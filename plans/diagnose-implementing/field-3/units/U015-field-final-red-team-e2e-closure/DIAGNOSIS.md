# U015 — Final exact-SHA Field closure

Final closure is deliberately stricter than the sum of unit tests. The repository has already demonstrated that Field implementation can move while old package evidence remains green or DONE, so U015 re-resolves the latest `A` candidate after the last product write and reruns every evidence class invalidated by subsequent changes. A package status, PR check from another SHA or historical device run cannot substitute for the candidate being released.

The final journey begins with Control Panel creating the independent Field provider through the canonical Workforce command, completes profile/readiness/activation and phone login, then exercises assigned and self-initiated partner/store onboarding, documents, event-based visit evidence, vertical checklist and Partners approval, catalog proposals/assortment, Marketing publication, Partner and Client positive/negative readback using the same IDs, policy-driven commission/payout/offboarding, offline/restart and native behavior. It also performs a tree/diff cleanup scan for dead routes/controllers/views/packages and specifically verifies that Field COD/incidents/penalties are absent. Only then may `CLOSED_WITH_EVIDENCE` be written and a PR to master opened.
