# U011 — Field commission, payout and offboarding settlement

WLT is already the correct financial owner, and the Field finance screen reads the provider's own wallet/ledger/commissions and uses a masked payout destination. That direction is retained. The diagnosed contradiction is that the same Field finance screen also renders `ProviderIncidentsPanel`, while Workforce exposes provider-incident/appeal/penalty flows. The approved product explicitly cancels Incidents/Penalties for Field and excludes COD completely. Those are deletion requirements, not optional hidden features.

Commission creation becomes policy-driven across approved field work events and is earned only after required evidence/result approval. Wrong commissions are corrected with append-only reversal/adjustment entries. Finance controls payout destination and configurable limits/fees; the provider requests only FULL_AVAILABLE or SPECIFIED. External payout keeps approve, execute, independent verify/complete and unknown-result reconciliation. If a provider is terminated, access is revoked immediately while an offboarding settlement case remains open until WLT resolves the balance. Shared Partner/Captain payout regression is tested only if the same underlying contract changes.
