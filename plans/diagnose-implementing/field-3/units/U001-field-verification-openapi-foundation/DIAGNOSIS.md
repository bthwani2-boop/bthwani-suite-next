# U001 — Verification and OpenAPI foundation

All earlier Field results were produced before the canonical rebaseline and therefore cannot establish current closure. The first execution step is not feature coding: it is resolving the latest `A` head and proving that the contract/materialization/install and app-field test/type/lint/build gates are genuine signals on one candidate. Any OpenAPI or generated-client failure is repaired in its canonical contract/composer source; disabling generation, skipping tests or accepting no-tests behavior is prohibited.

The current app-field runtime already has a unified test entry and dedicated tests for deep links, readiness and offline behavior, so this unit must not recreate an obsolete test architecture. It verifies the current architecture and adds only regression coverage needed for reproduced blockers. The output of U001 is a trustworthy baseline for every later unit, not a claim that Field product journeys are closed.
