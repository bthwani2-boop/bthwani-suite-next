# منطق تشغيل منظومة بثواني

هذا المجلد هو المرجع المركزي للنقاش والتوثيق الخاص بمنطق تشغيل منظومة **بثواني** بوصفها منصة **Full-Stack SaaS موحدة متعددة الأسطح**.

## الفرع الحاكم لهذه المسودة

`cleaning`

## الغرض

- تثبيت منطق العمل قبل تحويله إلى كود.
- تحديد مالك كل حقيقة وقرار وحالة تشغيلية.
- توحيد المصطلحات والتدفقات بين الخدمات والتطبيقات ولوحة التحكم.
- منع مصادر الحقيقة المتعددة والمنطق المحلي المتضارب والترقيعات.
- تسجيل النقاط المتفق عليها والنقاط المفتوحة والقرارات المؤجلة بوضوح.

## الوثيقة المركزية

`BTHWANI_UNIFIED_OPERATING_LOGIC_AR.md`

حالتها الحالية: **مسودة نقاش غير نهائية**.

لا تُعامل أي قاعدة داخل المسودة كقرار تنفيذي نهائي حتى تُصنف صراحةً بأنها **معتمدة** وتُربط بمالكها وعقدها وقاعدة بياناتها والأسطح المستهلكة لها واختبارات القبول الخاصة بها.
