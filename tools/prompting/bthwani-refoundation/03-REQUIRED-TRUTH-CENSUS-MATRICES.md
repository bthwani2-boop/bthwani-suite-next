# Required Truth, Census and Ownership Matrices

## 1. Purpose

No destructive refoundation decision is safe merely because a target topology looks cleaner.

Before demolition, reconstruct the required product/system truth and the complete affected cone from exact live `h`.

This file defines the required live reconstruction method. It is not a status ledger and must not be filled with durable campaign progress.

```text
REQUIRED_TRUTH_FIRST
→ CANONICAL_OWNERSHIP
→ COMPLETE_AFFECTED_CONE
→ LOSER_IDENTIFICATION
→ MIGRATION/CUTOVER/DELETION
```

## 8. Current names are forensic evidence, not target vocabulary

During census record aliases/current names so negative-space search can kill them, but choose canonical semantic names independently.

Actor/page/mechanism/generic names do not become owners merely because they are widespread.

```text
CURRENT_USAGE != CANONICAL
CURRENT_NAME != REQUIRED_TARGET_NAME
```
