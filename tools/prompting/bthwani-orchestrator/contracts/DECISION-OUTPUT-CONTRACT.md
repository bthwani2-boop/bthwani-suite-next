# Decision Output Contract

Status: DERIVED_SUPPORT / DOCUMENTATION_ONLY
Applies to: decision sections in `NNN-<sequence>.md`; only truly global decisions are summarized by reference in `00-OVERVIEW.md`.

## Decision Candidate

```text
QUESTION_CANDIDATE_ID
RELATED_FINDINGS
AFFECTED_GRAPH
DERIVABLE_FACT? YES|NO
EXTERNAL_EVIDENCE_GAP? YES|NO
TRUE_DECISION_CLASS
STATUS
```

Do not ask while `DERIVABLE_FACT=YES`.

## True Decision Record

```text
DECISION_ID
SEQUENCE_ID
JOURNEY / ACTOR / SURFACE / STATE
DECISION_REQUIRED
WHY_EVIDENCE_CANNOT_RESOLVE
CONTRADICTING_OR_MISSING_EVIDENCE
OPTIONS + tradeoffs
RECOMMENDATION + reason
AFFECTED_GRAPH_NODES
USER_OR_AUTHORITY_DECISION
DECISION_SOURCE / DATE when available
DURABILITY_CLASS
GOVERNANCE_OWNER_CANDIDATE
STATUS
```

Allowed true-decision classes: `CONTRADICTION / AMBIGUITY / MISSING_PRODUCT_OR_OPERATIONAL_DECISION / MULTIPLE_VALID_BEHAVIORS`.

## After Decision

```text
IMPACT_PROPAGATED = YES|NO
AFFECTED_SCOPE_REDIAGNOSED = YES|NO
CROSS_SURFACE_RECHECK = YES|NO|N/A
CROSS_LAYER_RECHECK = YES|NO|N/A
ADVERSARIAL_RECHECK = YES|NO|N/A
NEW_FINDINGS_OR_DECISIONS
GOVERNANCE_PROMOTION_STATUS
```

No unresolved material decision required for the current Sequence may be carried into its solution/write gate.
