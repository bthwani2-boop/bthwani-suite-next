# 06 — Concurrency, Resume & Recovery

Status: DERIVED_SUPPORT / DOCUMENTATION_ONLY

## Isolation

New invocation = new package/task branch. Resume = explicit exact package. Foreign sessions are inputs, never navigation. One writing owner per conflict domain; one Integration Owner per target.

## Resume order

```text
resolve latest target
→ classify foreign delta
→ restore ORCHESTRATION_ROOT / diagnostic altitude
→ revalidate operational-root registry against latest truth
→ invalidate affected categories/nodes
→ re-run negative-space/adversarial where affected
→ reconcile root-cause landscape
→ competitive deepening if ranking uncertainty can change winner
→ re-rank
→ derive current frontier
```

Persisted frontier is never automatic resume authority.

## Concurrent delta

```text
UNRELATED → preserve / no direction change
RELATED_NON_BLOCKING → attach to operational/root node; invalidate affected evidence only
UPSTREAM/ROOT/AUTHORITY_CHANGE → operational reconciliation + backtrack
BLOCKING → affected dependency/frontier only
DIRECT_CONFLICT → block conflict domain
```

## Lower-layer queue under concurrency

Foreign technical commits or newly seen CI/UI/code failures are observations until they acquire an operational parent and causal/priority placement. Recency never promotes them.

## Recovery

If task workspace/branch is stale, recreate/reconcile isolation before writes. If operational registry provenance is stale, no priority/frontier/write can continue. If integration target moves during final review, re-run affected machine gates before final decision.
