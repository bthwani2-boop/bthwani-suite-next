# H Relentless Continuous Refoundation Campaign Playbook

Status: ACTIVE_CANONICAL_ORCHESTRATOR_OWNER
Owner: A0/A1/A2/B continuous campaign traversal, interrupted-unit reconstruction, dominance selection, safe-checkpoint preemption, automatic causal continuation, no-idle enforcement, anti-endless-audit execution forcing and fixed-point traversal.

## 1. Campaign is one continuous engagement

The campaign is not a collection of independent tasks.

```text
STAGE_A0 — HOSTILE BRANCH-WIDE CATASTROPHE TRIAGE
STAGE_A1 — DOMINANT DESTRUCTIVE BASELINE REFOUNDATION
STAGE_A2 — ADVERSARIAL STRUCTURAL QUALIFICATION
STAGE_B  — NORMAL CAUSAL ROOT CLOSURE
```

```text
CAMPAIGN_ENGAGED=TRUE_ON_FIRST_MUTATION
CAMPAIGN_ENGAGED_REMAINS_TRUE_UNTIL_LEVEL_4_OR_LEGITIMATE_BLOCKER
```

## 2. Session entry and recovery

Every new/resumed session first reconstructs:

```text
PINNED_H_SHA
CURRENT_STAGE
LAST_PROVEN_CLOSED_UNIT
ACTIVE_OPEN_UNIT
ACTIVE_UNIT_STATE
PROVEN_COMPLETED_OBLIGATIONS
OPEN_OBLIGATIONS
MIGRATION_STATE
CUTOVER_STATE
LOSER_DELETION_STATE
PRUNING_STATE
VALID_EVIDENCE
STALE_EVIDENCE
RECOVERY_FRONTIER
NEXT_REQUIRED_ACTION
CURRENT_BLOCKER_OR_NONE
```

```text
NEW_CHAT != NEW_CAMPAIGN
NEW_CHAT != NEW_ROOT
COMMIT != ROOT
COMMIT != UNIT
```

If an active unit exists, continue from its first unfinished material obligation unless lawful higher-cause preemption applies.

## 3. Runtime state machine

Before completion, exactly one runtime state is active:

```text
RECOVERING
DISCOVERING
DIAGNOSING
SELECTING
DEMOLISHING
REFOUNDING
MIGRATING
CUTTING_OVER
DELETING
PRUNING
VERIFYING
FALSIFYING
RECENSUS
LEGITIMATELY_BLOCKED
```

There is no normal `IDLE` state.

Every non-blocked state must derive and perform its next legal transition.


## 7. Stage-B traversal

Stage B closes only true semantic/product/system roots inside proven canonical structure.

Cycle:

```text
REBUILD_NORMAL_CAUSAL_ROOT_GRAPH
→ SELECT_HIGHEST_CORRECT_SAFE_ROOT
→ DECLARE_COMPLETE_CAUSAL_CONE
→ SALVAGE_REQUIRED_TRUTH
→ REFOUND_OR_IMPLEMENT_CANONICAL_SOURCE_OF_FIX
→ MIGRATE_CUT_OVER_AS_REQUIRED
→ DELETE_ALL_LOSERS_AND_RESIDUE
→ PRUNE
→ FIX_ADMISSION_PREVENTION
→ VERIFY_AND_FALSIFY
→ RE_PIN
→ RE_DIAGNOSE
→ RE_RANK
```

Then execute the next root immediately.

If structural invalidity is discovered, A2 becomes stale and the campaign returns immediately to A0/A1.

## 8. Automatic causal continuation

Every completed action may expose higher or adjacent causes.

```text
NEWLY_EXPOSED_OBLIGATION
→ CLASSIFY_IN_CURRENT_GRAPH
→ ABSORB_INTO_CAUSAL_MODEL
→ PROMOTE_IF_HIGHER
→ RE_RANK
→ EXECUTE_HIGHEST_REQUIRED_FRONTIER
```

Do not merely list newly found defects while an executable frontier exists.

## 11. Checkpoint transition

A checkpoint is for recovery only.

```text
CHECKPOINT_CREATED
+ NO_BLOCKER
+ REMAINING_EXECUTABLE_WORK
=> CONTINUE_IMMEDIATELY
```

## 12. Safe-checkpoint preemption

`OPEN_CRITICAL` retains priority unless a higher systemic cause is a required prerequisite/superseding cause and can be safely promoted.

`OPEN_SAFE_CHECKPOINT` may be preempted by a proven dominant higher-leverage catastrophe when doing so does not create mixed authority or partial cutover risk.

This prevents a low-value unit from monopolizing the campaign merely because it started first.

## 13. No endless audit

Once:

```text
A0_ADMISSION=PASS
DOMINANT_CANDIDATE_PROVEN
NO_RANKING_CHANGING_UNKNOWN
SAFE_EXECUTION_PATH=PASS
PATCH_VS_DEMOLISH_GATE=PASS
DEMOLITION_PLAN=READY
```

then:

```text
MUTATION_MANDATORY
ANALYSIS_ONLY_CONTINUATION=FORBIDDEN_UNLESS_IT_CAN_CHANGE_SAFETY_OR_DOMINANCE
```

## 14. No waiting for human NEXT

When the next action is derivable and already authorized:

```text
ASK_NEXT=FORBIDDEN
ASK_CONTINUE=FORBIDDEN
WAIT_FOR_CONFIRMATION=FORBIDDEN
```

Human input is required only for a genuine stop state or unresolved product decision.

## 15. Git history is the archive

Do not preserve losing material in live `h` because it may be interesting later.

```text
DELETE_PROVEN_LOSER
→ USE_GIT_HISTORY_IF_FORENSIC_REVIEW_IS_NEEDED_LATER
```

Live `h` contains the canonical present, not historical exhibits.


```text

→ CONTINUE
```

## 17. Fixed-point traversal

When the Stage-B graph first appears empty:

```text
DO_NOT_STOP
→ FRESH_FULL_REPOSITORY_RECENSUS_FROM_ZERO
→ FRESH_FALSIFICATION
```

If anything material is found:

```text
REOPEN_CORRECT_STAGE
→ EXECUTE
→ CONTINUE
```

Only the Level-4 completion gate in `04` ends the campaign normally.
