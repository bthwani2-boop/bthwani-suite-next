# 01 — Core Contract

Status: DERIVED_SUPPORT / DOCUMENTATION_ONLY

## Constitutional model

```text
OPERATIONAL_TRUTH_RECONCILIATION → initial semantic authority
ORCHESTRATION_ROOT              → orientation
OPERATIONAL_ROOT_GRAPH          → material operational coverage
ROOT_RECONCILED_GRAPH           → navigation/dependency authority
ROOT_CAUSE_LANDSCAPE            → causal problem map
SYSTEMIC_PRIORITY_MODEL         → frontier selection
TASK_BRANCH/WORKSPACE            → write isolation
LATEST_HEAD                      → truth/integration baseline only
```

## FAIL-CLOSED

`UNPROVEN`, `UNACCOUNTED_MATERIAL_OPERATIONAL_NODE`, `UNMAPPED_MATERIAL_JOURNEY`, `STALE_OPERATIONAL_ROOT`, `LOWER_LAYER_HOLD`, `UNCLUSTERED_FINDING`, `UNRANKED_ROOT_CAUSE`, `STALE_PRIORITY`, `INVALID_FRONTIER`, `UNINTEGRATED_RESULT` كلها OPEN.

## Operational-first invariant

```text
NO ROOT-CAUSE LANDSCAPE
NO PRIORITY MODEL
NO SEQUENCE
NO EXECUTION FRONTIER
```

قد تصبح valid قبل أن يمر `operational-root-gate` على current reconciled SHA.

Technical/repository evidence يجوز قراءتها في أي وقت لإثبات/نفي فرضية أعلى، لكنها لا تمنح execution priority بذاتها.

## Escalate before fix

```text
symptom
↑ implementation
↑ contract/data meaning
↑ state/transition
↑ journey/handoff
↑ authority/ownership
↑ highest proven causal root
```

Lower-layer work لا يبدأ إلا بعد: parent understood + no unresolved higher upstream cause + graph position proven + priority justified.

## Package / isolation

كل invocation جديد = Package جديدة + Task Branch؛ Local writes = Worktree مخصص. Existing package resume بطلب مستخدم صريح فقط. Foreign delta input-not-instruction. One integration owner mutates target branch.

## Priority

`PRIORITY = HIGHEST PROVEN SYSTEMIC LEVERAGE`; finding count عامل تابع لا حاكم. Reconcile/re-rank بعد كل material discovery/fix/foreign delta capable of changing causal placement or leverage.

## Golden rules

```text
OPERATIONAL MEANING FIRST.
TOP-DOWN DIAGNOSIS; BOTTOM-UP EVIDENCE.
ESCALATE BEFORE FIX.
TECHNICAL FINDINGS ARE EVIDENCE BEFORE WORK.
THE GRAPH GOVERNS MOVEMENT.
ROOT CAUSE GOVERNS SCOPE.
SYSTEMIC LEVERAGE GOVERNS PRIORITY.
TASK ISOLATION GOVERNS WRITES.
LATEST HEAD GOVERNS TRUTH/INTEGRATION ONLY.
EVIDENCE GOVERNS CLOSURE.
UNPROVEN = OPEN.
```
