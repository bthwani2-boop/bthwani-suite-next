## Deletion protocol

For each retired skill directory: prove all consumers, migrate every reference to the registered tool policy, run registry/authority/reference guards, delete only after zero references, and rerun the same checks on the deletion commit. No compatibility shim remains unless a bounded, time-limited need is proven.
