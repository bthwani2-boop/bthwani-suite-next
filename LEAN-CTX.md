# LeanCTX Adapter

Use `governance/GOVERNANCE.md` and `AGENTS.md` for repository execution rules. The conditional LeanCTX tool policy is `.agents/tools/leanctx.md`.

LeanCTX may be selected only when it materially reduces repeated reads or noisy context. It cannot suppress exact evidence, required checks, blockers, remaining risks, or decision boundaries, and it owns no repository truth or approval.
